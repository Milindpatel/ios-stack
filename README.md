# iOS stack view tutorial

Two small UIKit projects that practise laying out screens with `UIStackView` and Auto Layout constraints so the layout adapts to every iPhone and iPad size. All the layout is in the storyboards; the view controllers have no code.

| Project | Path |
| --- | --- |
| stackView | `stackView/stackView.xcodeproj` |
| stak | `stackView/stak/stak.xcodeproj` |

## Running

Open either project in Xcode and run it on an iOS 15+ simulator. Use the device picker in Interface Builder to see the layout on different screen sizes. The projects use Swift 5.

CI builds both projects for the iOS Simulator on every push.
